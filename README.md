# 🚀 Vectorized Data Science & Scientific Computing

Bienvenue dans ce dépôt regroupant mes travaux sur l'implémentation d'algorithmes, l'analyse et le traitement de données, en utilisant **NumPy**, **SciPy**, **Pandas**, **Matplotlib** et **Seaborn**.

L'objectif de ce monorepo est de maîtriser le calcul matriciel, la vectorisation N-dimensionnelle (*broadcasting*), le nettoyage de données réelles et l'analyse exploratoire avancée sans dépendre de frameworks d'automatisation de haut niveau (comme Scikit-Learn ou AutoML).

> ✍️ **Engagement d'Autonomie :** L'intégralité du code, de la logique algorithmique et de la résolution des problèmes présentés dans ce dépôt a été conçue et rédigée manuellement, sans l'aide ni l'intervention d'une intelligence artificielle.
